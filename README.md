# EcoSave Club Frontend

Welcome to the EcoSave Club Frontend repository! This project is dedicated to the development of the frontend for the EcoSave Club website as .

## Project Overview

The Arts Club Frontend provides an engaging user interface for individuals interested in exploring EcoSave's activities, registering for events, and joining the club. It's designed to be intuitive, responsive, and visually appealing.

## Features

- Explore activities
- Register for events
- Join the club by sending requests
- Monitor registered activities

## Technology Stack

- Frontend: Angular

## Usage

To use the frontend locally, follow these steps:

1. **Install Node.js and npm:** [Node.js Installation Guide](https://docs.npmjs.com/downloading-and-installing-node-js-and-npm)
2. **Clone the repository:**

3. **Install dependencies:**

   ```bash
      npm install
   ```

4. **Run the development server:**

   ```bash
      ng serve
   ```

5. **Visit http://localhost:4200 in your browser to explore the EcoSave website.**
